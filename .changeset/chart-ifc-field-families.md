Element chart fields cover every IFC field family: `ElementFieldBinding` adds `quantity` (an `IfcElementQuantity` quantity, numeric in the project unit), `material` (associated material names), `classification` (reference identification, for any or one classification system), `type` (the defining `IfcTypeObject` name) and `spatial` (the containing `Container` / `Building` / `Site` / `Project`), with matching column identities, labels and dashboard validation.
