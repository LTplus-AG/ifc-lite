New **Charts** panel (#3944): a dashboard of charts bound to the loaded models, bidirectional with the 3D view. Click a bar or slice to select its elements (ghosting the rest by default, or isolate / highlight), pick in 3D to light up the matching bucket, and let one chart's selection slice the others. Sources: elements (type / storey / model / name across the federation, scoped to all models, the visible set or the basket), clash results, BCF topics, schedule tasks (phase at the playback cursor), IDS results and model compare, with per-week timelines over BCF and schedule dates; starter dashboards for model overview, coordination, delivery and schedule; "Colour in 3D" paints the model by the first chart's buckets. Cards sit on a drag-and-resize grid; dashboards persist like saved lists, and rename / duplicate / delete / export / import as `.ifclite-dashboard.json`; the first open seeds a *Model overview*. **Report** prints the dashboard to an A4/A3 PDF — vector charts, bucket tables, optional 3D snapshots of each chart's largest bucket, title block seeded from the 2D sheet — and remembers the setup as a report template. Bottom strip next to Lists and Schedule, in the ribbon's Analyze → Data group, the classic toolbar's Workspace menu and the command palette.
