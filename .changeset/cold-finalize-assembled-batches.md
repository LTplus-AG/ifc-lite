Finalizing a streamed load no longer rebuilds geometry the stream already uploaded. Each streamed bucket's final batch is now assembled on the GPU from the fragments that drew its meshes while streaming: a buffer copy, with indices rebased on the CPU. The old path merged, lattice-checked, quantized and uploaded every vertex a second time. A stream also keeps one f32 topology verdict per mesh and frame, instead of re-scanning each mesh four times, and the finalize regroup keeps buckets that no colour change touched. The rendered batches are unchanged: same frames, bounds, indices, LOD1 and decoded vertex positions. Quantized fragments of one bucket now share one lattice origin, which decodes to the same exact positions. A bucket that cannot be proven identical (f32 fragments, a lattice origin that did not fit, a mesh re-keyed while streaming, a fragment drawn before a scene-snapshot capture was armed) takes the full rebuild as before. A scene-snapshot capture keeps the assembly: while one is armed, each fragment keeps the vertex bytes it uploaded, and an assembled batch hands the capture those bytes concatenated in copy order, with its rebased indices and LOD1 indices. The snapshot bytes are what the GPU draws, as before. Load-trace counters `render.finalize.assembled.*`, `render.finalize.rebuilt.*` and `gpu.assembleCopy.*` report which path each bucket took. `quantizeInterleaved` takes an optional `LatticeFrame`, and `simplifyIndicesByClustering` an optional entity-lane offset.
