New package: the standard node library for `@ifc-lite/flow` over the ifc-lite SDK — `core.*` values and restructuring, `model.*` reads (selector, properties, quantities, relationships, storey grouping), typed `table.*` nodes, `viewer.*` feedback that is a no-op headlessly, capability-gated `model.setProperty`/`model.setAttribute`, and a sandboxed `script.run` node.
