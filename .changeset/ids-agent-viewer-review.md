The Assistant drafts IDS with the IDS agent (`Draft IDS with tools`) when your own Anthropic or OpenAI key is set. Accepted agent changes open in the same `Review IDS draft` card as a chat answer, so you can still edit the title, specification names and cardinality, requirement optionality and simple values, and see each declared unit read back in SI. Hosted free models keep drafting IDS through the chat's reviewed `ids.specifications` answer.
