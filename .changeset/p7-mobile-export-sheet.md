The mobile overflow menu has an Export sheet built from the export registry (#5842). On a phone the menu used to offer only a one-click "Export GLB", which disappeared once more than one model was loaded. Every format the toolbars and the command palette offer is now reachable (IFC, anonymized IFC, modified IFC, GLB, KMZ, USD, energy model, CSV tables, JSON, screenshot, 3D-view PDF, and installed extension exporters), and each one opens the same dialog or runs the same export as it does on desktop.
