Opt-in retained-geometry browser executor (#7955), in a separate engine bundle: the default engine is unchanged. `BUILD_RETAINED=1 scripts/build-wasm.sh` builds `pkg-retained` (the published package ships only its types), and `loadRetainedEngine()` from `@ifc-lite/wasm/retained` imports a deployed copy on demand; importing the loader fetches nothing. In that engine, `IfcAPI.retainedSources(bytes, ids?)` lists the authored extrusions and swept disks the retained route can represent, and every refused source with its reason; it is read-only and starts no Worker. `new RetainedBrowserExecutor()` is the only call that loads the separately deployed SMLib bundle from `/smlib/` (see `native/smlib-adapter/README.md`) and starts its module Worker. `executor.capabilities()` selects executable families from that actual Worker's SDK capability bits and its own witnesses: curved regions and rational disks stay closed until `qualifyNumericalRoutes()` passes on that Worker. `sources.execute(index, executor, chordMetres, angleDegrees, maxBytes)` evaluates one source and returns an `unstyled_flat_source_only` display: f32 evaluation-frame buffers and f64 row-major occurrence matrices to absolute IFC Z-up world metres. It is the raw authored solid only; openings, enclosing Booleans and styles do not apply, so it is not final product geometry. `executor.cancellation().retire()` stays callable while an execution is pending. Ordinary package use and model loading never request the retained bundle or `/smlib/`, nor construct the Worker.
