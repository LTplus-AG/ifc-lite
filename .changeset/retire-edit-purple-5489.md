Edit mode no longer has its own purple (#5489). The Edit toggle, Space Sketch, the ribbon's authoring toggles, the split guides and numeric input, wall endpoint handles, and the edit states in the Properties panel (geometry card, property and attribute editors, mutated-value highlights, georeference pin) now use the same interaction accent as every other tool, in every theme. While edit mode is on, a chip at the top left of the viewport reads "Editing · <model>" so you can see which model your edits go to.
