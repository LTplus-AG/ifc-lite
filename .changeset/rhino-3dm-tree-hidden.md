A loaded Rhino `.3dm` shows its layer tree in the hierarchy panel, with objects under their layer. A file whose layers carry the spatial stamps of an ifc-lite export gets a real project, site, building and storey tree with elevations, so the storey filter works on it. Objects and layers Rhino hides start hidden and can be shown from the tree, and a part hidden inside a shown element is not drawn. The model metadata panel lists the file's units, source application and document user text.
