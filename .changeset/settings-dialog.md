A **Settings** dialog is the viewer's one home for preferences. It opens from the ribbon's View tab (new Settings button), the classic toolbar's View options menu, and the command palette ("Settings…"). **General** holds theme, toolbar style and hover tooltips; **Display** holds Navigation → SpaceMouse, which moved here from the Info dialog's Preferences tab. The Info dialog no longer has a Preferences tab, and every SpaceMouse button now opens Settings → Display.
