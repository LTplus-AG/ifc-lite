The Sources browser shows each file's download progress: queued, a progress ring with its percentage (a spinner while the size is unknown), or failed. The browser stays open until the whole batch has downloaded, and stays open when a file failed so its row still says so. The Sync button on a loaded model, in the hierarchy and in the Sources browser, shows the same ring while the latest revision downloads.
