The reference collector treats a `/* ... */` comment as trivia, like the Rust exporter: an apostrophe in a comment no longer hides the references after it and a `#` in one is no reference. The merged exporter's id rewrite, drop analysis and in-attribute substitution share that rule, and a federated storey or container name now matches across models after STEP decoding.
