Save to source: a loaded IFC model from a source that supports write-back (Dalux) can be saved back as a new version, a new file in the same folder, or a new file in another folder. The dialog asks for explicit confirmation, uploads the edited model against the revision it was loaded from, reports conflicts without retrying, and lists the file's revision history after the save.
