When WebGPU support is still being checked, a model you drop or choose with the file input now opens by itself once the check passes. Before, the "WebGPU support is still being checked" card stayed up after a passing check. Only one open waits on the check: a second drop during the same check replaces the first, and the first file is not opened. Open (the file picker) and Start blank never open by themselves after a wait; a passing check clears their card. Retry works as before on the "WebGPU not available" card. It re-runs a drop, file input, `?model=` URL or Start blank once the re-check passes. It re-runs the file picker only while your click still counts as a user gesture (the browser allows about 5 s); after that the card clears and you click Open again. Pressing Retry while the first check is still running opens the model once, not twice. If resuming the open throws straight away, the error appears on the load-error card; later failures of the load itself report as they always did. If you switch language while a check is running, including the re-check after Retry, the card follows the new language and still changes to "WebGPU not available" when the check fails. A `?model=` URL still waits for the check to finish before loading.
