# Optional manual-validation report stamps (#6566)

The report's **Show stamp information** control hides both the Model/Recorded
row and the Models scope row. It defaults to shown for existing documents.
Preview and PDF use the same projection; hiding rows retains the recorded
timestamp, model fingerprint, model scope, verdicts and comments in the document.
