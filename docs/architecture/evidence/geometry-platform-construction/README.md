# Owned construction qualification

This receipt covers the typed processor registry, owned block/sphere/triangle
production lowering and explicitly partial raw-item construction batches. It
extends the [production phases](../geometry-platform-phases/) without rewriting
their historical source fingerprints. The exact kernel remains the production
boolean engine.

`source-manifest.json` identifies the uncommitted candidate and fixture/runtime
hashes. `validation.json` records commands, results and local raw-log hashes.
`default-path-perf.json` records base-versus-candidate whole-worker-pool runs,
including ordered mesh fingerprints. Raw logs stay at their recorded local paths;
hashes identify the actual logs, rather than reconstructed substitutes.
Fingerprints cover IDs/classes, geometry buffers, RGBA and frame fields. They
exclude text metadata, material definitions, UVs, textures and instancing; those
contracts need separate tests rather than a full-result byte-identity claim.

Constructor tests dispose of source bytes and decoder before replay, preserve
ordered repeated occurrences and reject incomplete batches. Production regression
tests cover survey-coordinate subtraction before f32 narrowing, millimetre scale,
rotated placement, PnIndex, closed winding and actual explicit UV corner pairing.
The real-file example repeats one authored triangulated item while retaining one
owned definition. Canonical model comparisons exercise the existing element path.

These are construction-layer preservation receipts, not a full operation-graph
or cutover qualification. Batch coordinates retain their documented raw file-unit
contract; its triangle admission omits RTC subtraction. Product/mapping placement,
openings, appearance and final publication remain canonical element responsibilities.
Root-count limits do not establish payload/process memory bounds. Shared-host
timings do not establish a latency non-regression or a speedup. No retained-BRep
throughput, all-platform packaging, memory win or complete capability claim follows.
