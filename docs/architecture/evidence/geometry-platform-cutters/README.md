# Owned cutter source and numerical seams

This receipt covers the cutter stage identified by
[source-manifest.json](source-manifest.json). [Validation](validation.json)
records completed native workspace tests and Clippy, fresh WASM checks with
fixture skips, raw real-file replay, the construction example and repository
guards. Earlier evidence directories retain their original scope.

[Worker-pool comparisons](default-path-perf.json) retain matching mesh counts and
ordered geometry fingerprints on the six measured models. Fingerprints omit UV,
texture, instance and text metadata. Shared-host timing remains unqualified.
[Native process high-water samples](default-path-memory.json) cover three models;
they do not establish browser/retained-plan memory behavior or process limits.

Production plane clipping now lowers source-space plane, normal and agreement
into an owned plan. Bounded polygonal cutters retain owned f64 Position and
sampled boundary data, then build their numerical prism against the current
host. Host-dependent extent, projection, winding and extrusion arithmetic remain
in the shared builder. These plans preserve file units before product placement,
router scaling and RTC publication. They do not introduce another boolean kernel
or restore analytic curves from sampled boundaries.

Production void-shell handling uses owned shell construction and shared void
subtraction. It retains conditional shell-by-shell admission: a failed or empty
shell refuses the cutter before later shells are read, and unit discovery occurs
only after successful shell preparation. Standalone and base BReps retain their
Outer-shell behavior. The opt-in construction graph distinguishes root, base and
operation roles in its definition keys, allowing a BRep with voids to retain its
cavity when used as an operation operand. Its eager source preparation remains a
separate contract from production's conditional reads.

Grouped polygonal-cut numerics are shared with production after the host and
prisms have been prepared. Their mesh inputs are numerical intermediates,
not source plans. Qualification must preserve trial-subtraction admission,
cutter union and repair decisions, removal bounds, full-host-removal protection,
and the distinction between a genuine solo cutter and a sequential step with
siblings. Provisional diagnostic rewinds must retain unrelated records and
must not refund consumed work.

Production polygonal-chain collection uses owned source-control snapshots with
the original conditional read order. Nonmatching operators stop before operand
reads; an unreadable or nonpolygonal second operand stops before FirstOperand;
a valid polygonal cutter enters the candidate before an unreadable first link
stops at the current node. Cutter order remains innermost first, and a cycle
retains the repeated current snapshot as the collector's base. Bounded use
reports source-limit exhaustion explicitly. Production retains its existing
iterative visited-set policy without adopting the opt-in compiler's limits.
The general full-spine lowering entry point remains test-only.

Qualification must demonstrate source disposal, unchanged geometry and frame
bits, agreement-side and cavity invariants, malformed-input read order,
conditional unit discovery, report isolation and recovery behavior. Direct
source refusal evidence must exclude unrelated sticky decoder refusals while
retaining a repeated refusal of the same referenced record. Captured reports
must not turn dormant source reads into executed losses. Half-space capping
still returns the current production mesh policy; this stage does not publish a
new guarantee that every clipped result is watertight.

The complete owned continuation evaluator remains pending. The optional graph
still admits constructor dependencies eagerly and has separate graph and
report-work bounds. Conditional source recovery, grouped-cut control flow,
contextual operand budgets and their interactions are not fully represented by
its executable instructions. Product and mapping transforms, appearance,
openings and final RTC assembly remain outside raw item construction. Mutable
kernel and element budgets also prevent assuming that shared definitions permit
memoized numerical results.

No production-wide cutover, speedup or memory reduction is established here.
Source snapshots, sampled arrays, shared definitions and intermediate meshes
can coexist; node and work bounds do not bound payload bytes or process memory.
The recorded worker-pool and native memory samples do not establish a performance
or memory improvement. Broad activation requires a qualified
shared evaluator for the complete control-flow contract and deletion of the
superseded decoder traversal. The
[capability ledger](../../geometry-platform-capabilities.md) remains the record
of outstanding coverage.
