## P2: editing an attached surface does not revoke constructor-only first issuance

`src/face_lineage_events.cpp:159–169` revokes `initial_issuance` for PRE/POST editing only when the notification caller itself is a face. For a surface caller, the bounded ownership walk correctly reaches its face (`geometry_face`), but lines 53–55 only reject a **complete** face; they neither revoke eligibility on an incomplete constructor face nor append editing history. PRE_EDIT is absent from that branch altogether. The later generic edit block returns without changing the binding because `face(caller)` is false.

Consequently, after constructing the actual planar patch inside `Phase::InitialConstruction`, an attached surface can receive a real notifying edit and the face still has its same incomplete Construct (or initial Add→Construct) node, live `newborn` flag, current frame and `initial_issuance=true`. `admit_roots` (`face_lineage.cpp:106–116`) therefore accepts it as constructor-only even though the stated first-issuance contract excludes subsequent edits. This is a source-level path, not a fabricated callback: pinned `SmPlane::TrimWithDomain` emits `SM_NO_PRE_EDIT` with the surface as caller at `SmPlane.cpp:3263`, then adjusts the actual analytic domain for a smaller contained interval. `SmPlane::Reparameterize` likewise emits surface PRE/POST at 3075/3120. `SmSurface::Notify` at 30324–30373 forwards through SmAObject, not through a face-level edit call. The current negative witness only replaces `face->SetSurface`, so it cannot catch this case.

Revoke first-issuance eligibility when an actual established owned surface/curve edit reaches an incomplete face (including PRE_EDIT), while retaining the precise documented initial attachment allowance. Any genuinely necessary construction-time edits need a separately bounded/authenticated initialization rule rather than a blanket incomplete-history exception. Add an actual SDK negative witness: construct the patch inside the audited phase, perform a checked notifying edit through `face->GetSurface()` (for example a contained `SmPlane::TrimWithDomain`), then require first root issuance to refuse. Keep the existing untouched patch→first root→checked-copy positive witness so the correction cannot silently disable genuine initial construction.
