# Authored evaluator source layer, round 1

This additive implementation starts at `fb913d3a5c`. It leaves the exact default,
borrowed producers, common BooleanProgram/effects, presentation/context owners,
USD mesh export and IFCX composition in place. No production activation or
qualified replacement is claimed.

The existing canonical authored plan supplies genuine raw rectangle profile and
extrusion data. A geometry document owns the immutable replay recipe, source
epoch/revision and distinct retained definition handle. Preparing a request
requires `RetainedBrep` and an explicit live worker incarnation. The Rust numerical
edge scales once into profile-local metres, retains the separate raw placements,
and returns both f64 inverse frames. The consumer composes the existing occurrence
matrix, including its source-unit scale, then explicitly changes matrix storage
for document occurrences.

One bounded transaction stages the numerical recipe through the same native and
browser decoder. Temporary SDK curves are owned locally, the actual capped linear
sweep creates a new solid, and manifold/analytic-volume checks precede publication.
Tessellation stays f64 with flat corner normals and revision-local face indices.
The processing consumer validates identity, revisions, frame and buffers before
publishing one deliberately narrowed display definition with every selected mapped
occurrence. Invalid completions are returned intact. New realization handles stay
worker-affine and require explicit release. Runtime loss never triggers replay or
an engine switch; stale completion admission requires a current incarnation.

Current IFC admission is deliberately restricted to source-only rectangles and
rigid mapped occurrences; nonuniform, scaled and mirrored occurrence transforms
are typed refusals pending qualification.
Original arbitrary trimmed-curve selectors and source angle-unit conventions are
not retained by the existing analytic extractor. Circle/holed/partial-arc region
qualification has not run. These families remain refused rather than converting
sampled contours into analytic curves. The low-level numerical circle producer
and its actual SDK witnesses are present solely for pending qualification. A
persistent IFC-face, analytic-normal or IFC-appearance consumer is explicitly
refused; no duplicated appearance resolver is introduced.
