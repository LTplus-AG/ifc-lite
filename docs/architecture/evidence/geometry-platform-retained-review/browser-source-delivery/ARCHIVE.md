# Evidence archive scope

This directory preserves selected original delivery manifests, review reports and execution receipts. Original `SHA256SUMS` files describe their original delivery directories, including files not duplicated here; they are not a checksum list for this archive. Historical observations are immutable, including running states superseded by a separately pinned terminal receipt.

Compressed logs retain the exact original uncompressed bytes. The source commits and file-hash manifests identify each reviewed or executed source. Later assembled commits require their own validation; packaging, source review, syntax and fixture-only checks do not qualify SDK geometry or the full migration.
