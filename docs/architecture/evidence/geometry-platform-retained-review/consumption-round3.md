# Retained authored consumption, round 3

Status: implemented source, qualification pending. Exact Rust remains the
permanent default. Retained execution is explicit; no loader, retry, fallback,
or engine switch is introduced.

The existing authored document and request now own a construction enum. Supported
extrusions lower ordered outer and inner line/arc/circle boundaries into the
existing bounded numerical region transaction. Original EXPRESS records,
selectors, basis frames, composite order and source winding remain unchanged;
only derived evaluation traversal is oriented for the SDK. Length conversion
occurs once in an object-local metre frame, with f64 occurrence placement outside
the kernel.

Supported open swept disks use the same request, runtime receipt and model-bound
acceptance. Exact rational B-spline controls, weights, degree, unique knots,
multiplicities and active basis range reach `CreateCanonical` directly. One
finite line or partial circular arc can also be converted algebraically to an
exact rational evaluation curve. This derived representation does not replace
its original line/circle, angle units or trim selectors. No curve is fitted to
samples. Hollow, closed and multi-segment disk paths, periodic/unclamped rational
curves, reverse/Cartesian-master rational trims, and general rational planar
regions return explicit unsupported outcomes.

Source capture is bounded independently of interpreted geometry. A failed
capture clears its graph and reports `capture_status = Unsupported(reason)`;
ordinary analytic line/arc geometry keeps its prior status. Faithful retained
admission requires complete capture. This preserves the existing scanned-record
standalone policy and authenticated decoder/cache canonical policy in one walker.
Bound analysis is weakly cached by the actual decoder instance and mutation
generation. A second decoder in the same production context keeps its own
supported input configuration; cache clears, drains and checked transfers recompute
analysis. Ordinary lazy memoization preserves sharing for repeated admission.
Original solid attributes and Position/Axis/RefDirection coefficient records are
captured separately from the derived frame; profile boundary graphs remain
separate. Capture failure does not change ordinary extrusion geometry status.
The earlier nonunit line allegation was withdrawn: the actual strict line path
normalizes DirectionRatios before applying Magnitude. A scaled-direction
invariant covers that behavior.

Feature negotiation never qualifies a target. Ordered regions and rational disks
remain blocked on a fresh native incarnation until the caller explicitly runs
its actual SDK numerical witnesses. Those observations apply only to that
incarnation and their reported numerical invariants. Native CTest additionally
contains actual surface-class and section-curve witnesses; module/browser
contracts are independent execution requirements. Witness source and syntax or
protocol checks are not successful geometry evidence. The first linked native
round-3 SDK run built successfully but failed its planar/curved surface-count
witness; transport and framing passed. Geometry qualification remains closed
pending diagnosis and a successful corrected target run. Browser numerical
recipes are distinct from the still-required canonical source-bound browser
consumer and cannot qualify that consumer.

Each created object has a registered liveness capability for its exact
session/slot/generation. Public release invalidates it before dispatch; an
uncertain release outcome retires the captured process without retry. Sealed
source and dependency receipts require both live object and live process, so a
released BRep cannot pass model-bound acceptance merely because its process
survived.

Retained Boolean dependencies resolve sealed operands into one f64 common local
metre frame. The SDK copies before transforming and before Boolean mutation;
shared sources remain immutable. Results own a mesh, source/operation lineage,
actual object/process authority and exact input-operation-frame identity for the
canonical pending slot. An opening uses the same Difference operation. These
numerical receipts do not certify complete representation or final-net coverage.
The common ProductProgram owner must consume every reached Boolean/opening
branch under its own source/context, sequence, occurrence and resource-generation
checks before final publication. This layer adds no parallel orchestrator.

Appearance, UVs, smooth analytic normals and persistent IFC face provenance remain
explicit refusals. Revision-local SDK face indices are never IFC identity.
Existing exact/mesh USD and IFCX contracts remain independent; retained USD,
complete representation accounting, imported-format retained consumers and the
full native/browser application binding remain open coverage obligations.

Performance and memory verdict: UNQUALIFIED. No base/branch whole-worker-pool
measurement or output-identity comparison has been completed for this source.
The delivery records actual command receipts, skipped/unrun coverage and
independent review responses. Historical receipts and the original unknown
request remain unchanged.
