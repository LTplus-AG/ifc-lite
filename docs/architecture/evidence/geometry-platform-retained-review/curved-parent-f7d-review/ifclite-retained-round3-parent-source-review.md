## Concrete behavioral blocker: one context caches the wrong decoder's source facts

`processing/src/authored_geometry/bound.rs::admit_authored_plan` authenticates the supplied decoder against SourceBundle, leases it, then returns the context OnceLock's first plan regardless of which authenticated decoder produced it. SourceBundle authentication deliberately does not canonicalize away valid first-record prewarming. Existing public source/cache behavior permits different selected duplicate records in two equally authenticated decoders over the same bundle. Therefore the plan is not solely a function of the current cache key (context).

The delivered `retained_admission_policy.rs` already provides a real distinguishing fixture: product31 has an earlier source12 and later source900; relationship910 has earlier opening920 and later opening921. Its current warm/fresh tests use **different contexts**, which conceals this collision.

Minimal same-context invariant:

1. Create one SourceBundle from that fixture, one ProductionModel, and **one** OwnedMeshProductionContext.
2. Factory decoder A prewarms the first original product31 and relationship910 via scanner spans and the supported decode_at_with_id API. Admit A: it correctly yields source12/opening920.
3. Factory decoder B from the SAME bundle is fresh. Its actual decode_by_id31/910 selects source900/opening921. Admit B through the SAME context: validation succeeds, but the current OnceLock returns A's Arc/source12/opening920 without reading B.
4. Reverse admission order: B's last-record facts now mask A's legitimate first-cache facts. Both variants should be tested.

The issue is not that the index should pick a different duplicate or that warm caches should be cleared. Canonicalization/reindexing would repeat the earlier preservation defect. It is a cache identity mismatch between the actual selected source state and its memoized plan. This is a real new API behavior defect even though default production has not activated this retained route.

Smallest coherent correction: replace the unconditional OnceLock with a cache entry that also records the actual decoder `ExecutionIdentity` (owner plus relevant configuration/cache generation). Reuse only an exact matching binding; on mismatch recompute through the supplied already-authenticated/leased decoder and replace the single entry. Compute without keeping a cache mutex guard across source traversal. Retained external Arc plans remain immutable historical snapshots under their existing lifecycle token. A one-entry replacement avoids unbounded strong per-worker caches and needs neither a second decoder nor an index clone.

Existing clear/drain/import/source-cache-transfer mutators change decoder generation and must invalidate this memo. Ordinary canonical cache fills need not invalidate a completed full plan, but verify that every operation capable of changing selected source facts is covered; do not assume a content hash, same bundle, unit scale or equal entity IDs proves it. If an alternate explicit incompatible-owner refusal is chosen, document it as a new admission restriction rather than claiming arbitrary same-context worker reuse. The full goal favors correct recomputation rather than refusing an otherwise valid worker. Add same-owner clear/re-prewarm and same-owner unchanged-cache reuse invariants as well as the two-worker cases.

## Capture failure and ordinary analytic compatibility: repaired in the inspected paths

`geometry/src/analytic/source.rs::SourceCapture::record` now records capture failure as data instead of propagating it into the ordinary curve interpreter. Failure clears all records, disables subsequent capture, and preserves its first reason in `capture_status = Unsupported`. `finish` also handles invalid source angle scale in that separate status. A partial graph is never marked Complete.

`CurveWalk::extract_inner`, composite segment handling and trimmed basis handling call record without `?`; their interpreted line/arc extraction follows its original Result/status contract. Parameterized profile capture is performed after ordinary profile parsing; curve_loop attaches source metadata separately. A capture-only malformed EXPRESS edge, record cap or value cap can thus leave ordinary line/arc/profile geometry Complete while its provenance is explicitly unsupported. `extract_owned_directrix` likewise distinguishes interpreted geometry status from capture status. Rational extraction itself requires complete source capture because it derives its coefficients from that graph.

Retained extrusion `validate_source` refuses any boundary whose source graph is absent/incomplete or lacks its root. Retained disk lower requires the complete solid/directrix capture rooted at the actual solid ID. No faithful retained admission treats the ordinary Complete status alone as provenance proof. I found no remaining unconditional capture-error return in these inspected ordinary geometry paths.

The new malformed coefficient-edge, profile area/perimeter, actual record/value-budget and scaled direction/master-representation invariants test the relevant distinction; they are unrun in this review. Capture still performs extra source reads and cache/refusal side effects, so this source verdict does not establish identical complete diagnostic/read traces for all old standalone inputs. Qualify those observable channels separately rather than treating geometry status preservation as all-channel equality.

* Curve source records retain original typed selectors, basis references/placements, SenseAgreement, MasterRepresentation, composite Segments/SameSense/Transition, raw points/directions/vector Magnitude and plane-angle scale beside interpreted radian/line traversal. The finite open/non-self-intersecting/clamped rules and forward parameter-master trim admission are explicit; reverse/Cartesian-master rational trims, periodic/unclamped and unsupported topology refuse. Parameter restriction does not normalize the original knot domain or widen a trimmed source.
* SweptDisk stores original StartParam/EndParam and its original solid/directrix graph. Old line/arc status remains separate from new owned rational input. Processing explicitly admits a complete retained-rational source even when the old line/arc view reports unsupported, then preserves world transform and source-only evaluation requirements. This is an actual new consumed family, not sampled segments presented as original coefficients.
* AuthoredRetainedDocument selects an owned RetainedConstruction enum for extrusion or swept disk; GeometryDocument stores it, prepares its request, validates it and publishes through the existing shared display consumer. The worker numerical route consumes its lowered region/disk payload. This is real source/document consumption, although complete ProductProgram representation/Boolean/opening activation remains outside it.
* Region lowering handles ordered outer/inner line/arc/circle boundaries, compares derived and source signed area and continuity, and reverses only the derived SDK traversal to orient outer/holes. Original source winding/records remain untouched. No polygon fit or sampling is introduced. Existing analytic topology validation remains the admission authority; malformed topology does not become empty evaluated success.
* Extrusion frames retain the existing raw profile Position, solid Position, direction/depth and length scale. Conversion is once into profile-local metres; f64 inverse frames remain outside the kernel. Disk coefficients are translated by the first control point and scaled once into local metres, while weights/knots/parameter range stay unscaled. A single finite line or partial circular arc is algebraically converted into an exact rational evaluation curve; original source coefficients and trim/angle facts remain separate. No sampled curve fitting is used.

One provenance limit remains: `AnalyticExtrusion` retains solid Position ID plus its derived f64 matrix, raw extrusion DirectionRatios and depth, but boundary SourceCapture does not record the original IfcExtrudedAreaSolid / solid Axis2Placement3D / Axis / RefDirection graph. The geometric frame is preserved; do not describe it as verbatim complete original solid-placement EXPRESS metadata.
