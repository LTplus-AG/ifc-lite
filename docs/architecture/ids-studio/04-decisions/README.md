# Architecture Decision Records

Format: Michael Nygard ADR (Context, Decision, Consequences, Alternatives). Status values: Proposed, Accepted, Superseded.
All ADRs are **Proposed** until the maintainer accepts them in the campaign PR/decision record under D8 (no charter issue prerequisite). The ADRs name no vendors or clients, so they can be copied to `docs/architecture/decisions/` in the public repo.

| ADR | Title | Status |
|---|---|---|
| [001](ADR-001-canonical-document.md) | Canonical document = `@ifc-lite/ids` types + Studio sidecar with stable IDs | Proposed |
| [002](ADR-002-typed-operations.md) | All mutations are typed, invertible operations shared by every surface | Proposed |
| [003](ADR-003-grounding-gate.md) | A grounding gate validates every operation before it applies | Proposed |
| [004](ADR-004-headless-packages.md) | Headless-first package split | Proposed |
| [005](ADR-005-writer-in-ids.md) | Move the IDS writer into `@ifc-lite/ids` and make it total | Proposed |
| [006](ADR-006-audit-vs-lint.md) | Separate Audit (conformance) and Lint (meaning) engines, one Diagnostic shape | Proposed |
| [007](ADR-007-no-canvas.md) | No node canvas: outline + inspector + grid + 3D | **Accepted** (owner decision 2026-10-08) |
