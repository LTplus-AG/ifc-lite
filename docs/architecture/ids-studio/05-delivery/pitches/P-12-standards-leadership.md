# P-12 — Standards leadership

**Problem.** Tools disagree, and nobody shows how. IDS 1.1 is coming, and whoever is ready first shapes adoption.

**Appetite.** 12 weeks (C7–C8), Track A.

**Solution.**
- An IDS 1.1 preview behind a flag.
- A public conformance dashboard that runs open engines and the official audit on the corpus and shows the agreement matrix.
- Upstream contributions: ambiguity write-ups linked to our lint rules, and test cases from our fixture generator offered to the corpus.

**Rabbit holes.** Running other engines in CI (Python/.NET runtimes). Keep it to open-source engines with permissive CI use.

**No-gos.** No claims about commercial tools we can't test reproducibly.

**Scopes.** IDS-124 … IDS-126.

**Done means.** The dashboard is public; 1.1 preview features are usable with a clear label.
