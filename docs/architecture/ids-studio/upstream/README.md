## Proposed corpus cases

`proposed-corpus-cases/<folder>/<prefix>-<name>.ids|.ifc` follows the corpus
naming convention. The `.ids` files are written by `writeIdsXml`, the
`.ifc` files are minimal hand-written IFC4, and both are regenerated by:

```bash
pnpm turbo build --filter=@ifc-lite/ids...
node scripts/ids-conformance/proposed-cases.mjs
```

Folders starting `ids11-` hold IDS 1.1 candidates, written with the IDS 1.1
preview. They are proposals for the 1.1 corpus, not for 1.0. They are our
own files (MPL-2.0 in this repository) and no derivative of the CC BY-ND
corpus; offering them upstream means licensing them to buildingSMART on the
corpus's terms, which is the owner's call.

## How to send

1. Post each note's "Proposed resolution" as a comment on the issue it names,
   linking the conformance dashboard (`docs/guide/ids-conformance.md`).
2. Offer the proposed cases as a pull request against the upstream
   `development` branch (test cases live under
   `Documentation/ImplementersDocumentation/TestCases`), one folder per note.
