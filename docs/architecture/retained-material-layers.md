# Retained material layer continuation

The opt-in shared native/browser controller captures strict source bindings for
`IfcMaterialLayerSetUsage`. After its ordinary issuance loop completes J2, call
`issue_layer_partition`, execute the returned packet with the same runtime, and
call `accept_layer_partition`. `RuntimeProductWitness::layer_manifest()` then
exposes all completed capped bands in authored material order. Final publication
still refuses: persistent face identity, cap removal and appearance remain
independent obligations. All new runtime tests and mutations are **UNRUN** until
the parent validates the integrated source.

Source admission retains context, association, usage, layer-set, layer/material
ids, ordinal, units, direction and canonical product placement. Invalid or
collapsed thickness, dangling references and ambiguous usages refuse the whole
stack. Absent optional material remains an air gap; no visual merging occurs.

## Distinct derived contract

Generated interfaces are not authored `IfcHalfSpaceSolid` or `IfcPlane` entities.
`DerivedLayerBinding` binds the captured usage/context, source epoch/revision,
original J2 net-host logical definition and occurrence, physical evaluation
frame, band ordinal, and complementary sides of its two boundary ordinals.
`DerivedMaterialRegion` and `DerivedMaterialIntersection` are separate invocation
variants. They use the existing retained sweep and Boolean runtimes, with shared
receipt validation against the exact issued request, runtime domain, ordered
host/cutter objects, frames and authenticated Empty outcome.

`RetainedRecipe::DerivedLayer` is distinct from an authored extrusion. Its private
numerical encoding view clears captured source graphs from generated boundaries.
No STEP entities are fabricated, and no generated face acquires IFC face ancestry.
Direct display publication of a derived construction is refused.

## Proved finite circular family

The current source proof admits one positive-sense finite trimmed circular wall
Axis in product XY and one direct Z extrusion of the matching annular sector.
The circle basis, trim, body/profile coframe, radii, radial closure lines, units,
extrusion and complete stack extent are checked before lowering. Every band
reuses the same finite angular and height extent. Strict monotone radii partition
that complete source body; consecutive bands share an identical radius with
opposite traversal. Negative material direction preserves authored material order.
The existing numerical region bounds, area checks, minimum lengths, circle and
frame guards remain in force. No tolerance is widened.

Each region is intersected with the original authenticated **net host after
openings**. J2 subtraction makes this a subset of the proved body. Complete finite
regions partition that body, so their intersections partition the net host;
there is no giant cutter, mesh clipping, incremental remainder drift or automatic
exact fallback. The original host and its opening ledger are preserved.

The packet owns all temporary receipts. A cancelled or failed in-flight packet
retires its captured domain. A foreign source/owner epoch, replayed issuance,
missing band, wrong receipt or frame rejects acceptance. The complete manifest
is installed once, after all fallible validation. Empty bands are authenticated
Boolean outcomes, never inferred from missing geometry. All-empty completion
retains the existing whole-product removal refusal.

Mapped bodies, multipart hosts, other curve families, nontrivial profile/solid
coframes, reversed axis traversal and product-axis layers currently refuse
explicitly. They remain required full-J3 work, not release exclusions. Product
placement and RTC are separate from the local sector proof; translated/rotated
product and millimetre cases have test definitions but no runtime qualification.

## Validation definitions

`curved-oracles.json` retains its original fixed two/three-band net volumes and
tolerances. New native and actual Worker tests consume **completed bands** after
the opening subtraction. They assert volume, radial/height section extents,
material order, remaining J5 holds, and no committed consumed-host effects.
Variants cover negative direction, millimetres, product placement/RTC and explicit
mapped refusal. The original metadata-only tests remain as source tests.

CI retains the four original source mutations and adds three independent reverse
mutations for source/body coverage, issuance authority and partial commit. Their
runner requires the named behavioral failure and restored green; compilation
errors, skips or zero selected tests cannot qualify a mutation.

No performance or memory verdict is claimed. Parent validation must run native,
actual Worker, clippy, the protected14/inherited61 and all J3 mutations, exact
identity and end-to-end performance/memory checks. Concurrent association-index
initialization and cache/account lifetime qualification remain open.


## Source-protected opening removal (#7955)

The disabled retained transaction now distinguishes a source-protected whole-product
opening removal from an unproved numerical Empty. Native and browser execution
share `session_retained/removal.rs`, reached by the original product continuation
after its ordered Difference receipts have authenticated. Exact remains default.

The initial policy accepts direct Body rectangular extrusions in the same authored
frame, with axis-aligned raw profiles and positive finite dimensions. Each terminal
host part must have an authenticated opening cut whose source solid contains the
**entire original host part**. This is solid containment in this closed domain,
not containment of an arbitrary solid's bounding box. The proof reads the immutable raw STEP records, never the decoder's rounded
coefficients. Checked i128 arithmetic on a 10^-18 raw-unit grid proves equality
and ordering; endpoints are doubled so half-dimensions remain exact. This also
preserves input errors that would otherwise disappear during floating-point
cancellation. Unsupported precision, range, schema or arithmetic overflow refuses.
Rotated profiles, mappings, pre-empty hosts, unknown shapes and cumulative removal
without one containing cutter remain explicit policy refusals. Shared product
translation and multiple direct host parts are supported. Coframe authority comes
from exact sums of authored IfcLocalPlacement translations, not equal rounded
matrices. Each placement has canonical exact axes or explicit `$` defaults;
missing/`*` attributes, wrong 2D/3D schemas, cycles and noncanonical axes refuse.
Rotated product frames remain outside this closed proof domain.
No threshold in the exact kernel or its retention protections changes.

Policy admission checks source epoch/revision, product and occurrence slots, ordered
cut lineage, source Body membership, canonical placement and the actual
IfcRelVoidsElement relationships against the selected index. It decodes only the
source records needed for that proof: no later opening body is fetched after all
host parts become authenticated Empty. A malformed reached opening still fails the
whole transaction. Unknown outcomes, cancellation, stale sources, foreign receipts,
and replay cannot grant removal. There is no partial retained output or automatic
retry with exact.

`has_authenticated_opening_removal()` on the execution or owned witness reports
this provisional proof only while its source and numerical evidence remain valid.
The proof is private, non-cloneable, bound to the final slots, and moved once into
the owned witness. Cancellation discards it; a failed policy leaves no traversal
plan. Router consumed-host effects remain unpublished on every intermediate path.

This does **not** enable final output: `require_final_product()` still refuses.
Layer partition/cap cleanup, appearance, persistent face identity, final geometry
validation and viewer/CLI publication remain terminal dependencies. Their eventual
publisher must consume this evidence together with all complete product gates and
commit the consumed-host effect exactly once under the original publication owner.
There is intentionally no independently callable effect-commit API. The current
user-visible behavior remains an explicit retained final-publication refusal;
source-protected Empty is available as intermediate transaction evidence, not as
permission to hide a product in the viewer. Runtime qualification of this policy
requires the native and actual Worker tests and mutation rounds; static inspection
alone is not acceptance.


R1 decimal proof bounds: each raw record is at most 4096 bytes, numeric tokens
at most 64 bytes/36 digits, exponent -18 through +18, and the scaled coefficient
must fit i128 exactly (no rounding to the grid). Placement chains are iterative,
cycle-checked and limited to 64 links. The proof borrows source tokens, uses fixed
stack arrays, and charges work before record scans and arithmetic. It allocates
no big integers or owned token copies. It reuses the core StepRecord,
StepListItems, STEP numeric grammar and quoted-string scanner used by #3641's
lexical source validation; the existing #3641 implementation is unchanged.
The exact rational residuals in regression sources are a 10^-16 top slab and a
0.3-wide strip after cancellation, plus a 10^-16 authored placement difference.
These are source proof obligations, not permitted geometric tolerances. Native
and actual Worker negative definitions deliberately require the policy refusal;
an earlier SDK failure does not qualify those tests. All final-publication holds
above still apply; this correction does not complete J2.


R2 vector grammar: a raw coordinate/direction attribute must consume exactly one
list value. The canonical `StepListItems::fully_consumed()` check requires the
list terminator to be followed only by STEP trivia, rejecting suffixes such as
`(1.,0.)BOGUS` for both directions and points. Its existing `closed()` prefix
contract is unchanged for record readers. Numeric item grammar remains the
shared STEP numeric grammar; no additional numeric parser is introduced.
Direct predicate controls require the specific protection-policy refusal and
preserve valid/comment-trivia inputs. Native and actual Worker definitions
require that same policy refusal after real execution; incidental SDK errors
fail those definitions and do not count as qualification. All runtime execution
and final J2/publication gates remain held pending parent validation.


R3 complete-record authority: every J2 proof record read now passes one bounded
`removal_record::read` admission before raw access or decoded lookup. Canonical
`StepRecord::parse_complete` requires a valid simple-record head, the complete
argument-list terminator, legal trivia, a required semicolon and only trivia to
the supplied raw-span end. Historical `parse`/`closed` readers keep their prefix
contract. This framing check deliberately leaves attribute schema to the caller:
vector lists still require `fully_consumed`, scalar decimals/references are whole
tokens, and Body membership lists and representation identifiers now receive
complete list/reference/string checks. Product/coframe records, placements,
primitives, profiles, shape representations and void relationships all use this
admission. No J3 code or numerical parser changes are included.
Source proof tests cover adjacent lists, keyword/list suffixes, extra closes,
comment-adjacent suffixes, nested-member tails, coframe records and relationship
references, with valid record-trivia controls. SDK and Worker definitions require
actual source-policy refusal, not incidental errors. All execution and final
publication holds remain unchanged.
