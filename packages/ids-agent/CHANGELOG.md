## 0.2.0

### Minor Changes

- [#7148](https://github.com/LTplus-AG/ifc-lite/pull/7148) [`42f66fb`](https://github.com/LTplus-AG/ifc-lite/commit/42f66fb3a0b10786445ab1714c0b2a2d9ea3f20a) Thanks [@louistrue](https://github.com/louistrue)! - New `@ifc-lite/ids-agent` package: the IDS authoring agent. `runAgent` runs a tool-calling loop over the op vocabulary of `@ifc-lite/ids-authoring` on a sandbox fork, so every change passes the grounding gate and a hallucinated name comes back to the model as a refusal with candidates. Tools cover the IFC schema tables, the working document (read, apply ops, undo, lint, quick fixes, unresolved statements, structured `ask_user` choices), loaded models through a `ModelBridge` (with a message-port worker bridge) and bSDD through a `BsddClient`. The run stops on end of turn, root budget, repeated failures (no progress), cancel, timeout or wall clock, and returns a reviewable `Proposal` with sources, previews, a usage and cost receipt and a payload digest; `acceptProposal` re-gates the chosen batches against the live document and commits them as one undo step. Modes: Draft, Edit, Explain, Repair, Review, Infer and Translate, with a versioned system prompt. Adapters: `@ifc-lite/ids-agent/anthropic` (default `claude-opus-5-5`) and `@ifc-lite/ids-agent/openai`; `@ifc-lite/ids-agent/testing` has scripted models, recorded transcripts and bridge doubles. `privacyView` reports exactly what each request sent.
