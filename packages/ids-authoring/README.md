# @ifc-lite/ids-authoring

Headless authoring core for IDS (buildingSMART Information Delivery
Specification) documents. Every surface that edits an IDS (a UI, an AI agent,
an import, the CLI) changes it only through the typed, invertible operations
defined here.

Work in progress: this package is being built in the IDS Studio campaign
(pitch P-02).
