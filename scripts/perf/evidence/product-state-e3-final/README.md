# Final canonical product protocol evidence

`summary.json` identifies the measured source, parent, jobs, original artifact
hashes, scopes and adverse verdicts. `native-report.json` and
`browser-report.json` retain the stock metric and noise decisions. Their sample
files preserve all original measurement rows; the declared transformations
remove machine paths and host environment details only. Public fixture names
map the native bundle names back to the source models.

`identity.json` reports the separate native and source-built WASM comparison.
`correctness.json` records workspace/Clippy and observed semantic mutation
controls. `instruction-attribution.json` is a separate serial diagnostic, not
an elapsed-time replacement or a browser qualification.

All raw original receipts, console logs, screenshots and source/runtime
inventories remain retained by the submitting session. The original native
qualification is false, and the browser first-batch regression remains
flagged. See the performance ledger for the correctness tradeoff and remaining
scope. This directory grants no retained activation, release or distribution
clearance.
