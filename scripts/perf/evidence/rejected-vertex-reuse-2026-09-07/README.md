# Rejected constraint-inventory vertex reuse (#4055)

The experiment is stopped without landing its production code. Reusing the constraint inventory during CDT refinement did not establish a substantial cold-load gain, and the corrected browser comparison failed the original geometry and lifecycle gates. This record closes the experiment; it does not approve a narrower implementation or relax qualification.

- [Native evidence](native-five-pairs.json) records all twenty-seven fixtures, five interleaved fresh-process pairs each, per-pair elapsed times, phase medians and the frozen probe identities. The complete processing call excludes file reading, post-timing fingerprints and result disposal. It is not the HTTP endpoint. The ratio-of-model-medians aggregation gives about 1.17% less time; the median-paired-ratio aggregation gives about 1.27%. Those are different estimators, retained separately. Every compared native payload witness matched within its documented scope.
- [Browser evidence](browser-screen.json) records a single pair per fixture with corrected orientation on both sides. The historical eleven-model subset was about 0.63% slower in complete readiness. Twenty-four pairs passed the acceptance checks; three did not. The accepted subset was about 0.37% slower in readiness and 0.48% faster in geometry completion. This is not a qualified whole-corpus gain or evidence of regression freedom.
- [Canonical diagnostic](canonical-diagnostic.json) records exact producer-payload agreement for the 263 MB fixture using private instrumentation. It supplies no timing evidence and does not waive either arm's downstream raw geometry or spatial gate.

The 1.259 GB fixture completed functional checks in both arms, then both hit the browser-close watchdog. Both attempts remain unqualified. The original following three large-fixture pairs lacked a contemporaneous process-exit boundary witness and remain archived as contamination-uncertain. Only those affected pairs were repeated with explicit Chrome process disappearance checks; their clean recovery pairs passed. The original attempts were not overwritten, and the watchdog-failing fixture was not retried to obtain a passing result. The close hang remains unexplained.

The 511 MB and 263 MB fixtures passed functional checks but differed in raw mesh counts, canonical hashes, AABB/volume channels and spatial result multisets. These comparisons remain rejected. No mesh normalization, route equivalence or native canonical substitution was used to turn them into passes.

Native probes were frozen on the earlier source lineage identified in their artifact records. The browser cohort instead used the final corrected #4058 viewer assets on both sides, with hash-verified context-level WASM overrides; the candidate differed only in the constraint-inventory kernel files. The orientation correction leaves the native canonical producer unchanged, but these remain distinct experiments and their percentages must not be pooled. The browser screen verified fixture hashes, frozen assets, served base runtime and override bytes outside model timing. Fresh processes alternated order per fixture on the same Chrome release. OS file cache was uncontrolled. No Firefox corpus or production-deployment claim is made.

These JSON files are sanitized projections of preserved private evidence, linked by source-record hashes. They omit local paths, source model names, property values and screenshots. The full native payload hash excludes text metadata, material definitions, UVs, textures and instancing as stated in its scope; matching hashes do not establish those omitted properties or universal closure. Failure records and original uncertain attempts remain part of the experiment's disposition.
