# Cold-load validation evidence

This bundle records the retained loading changes, their matched runtime evidence and their limitations. It is not a deployment record or a declaration that every check is green. Numeric measurements live in the JSONL records. Each record is an explicit projection of retained evidence; original records remain unchanged and are identified by archive ID, content hash and, where needed, an object selector. Archive IDs are evidence identifiers, not promises that private originals are publicly downloadable.

The combined native processing probe improves full-call loading across its fixed corpus. Its allocator and processing-example entry point differ from the actual HTTP server, so it does not qualify that server. The standalone layer results are mixed: several show no measurable isolated throughput win, and layer E is slower on its selected subset with unresolved causal attribution. Layer B also has a separate matched Chrome subset with flat full-readiness and geometry medians. Its native subset is slightly slower, and no isolated throughput win is claimed. Its original console-error audit remains failed with the same explicit environmental disposition and historical URL limitation, confirmed by a separate diagnostic on its exact frozen servers. Metadata console-receipt differences are not parser-only CPU measurements. Memory improvement and a better combined result do not erase the standalone costs. All pairs and outliers remain included.

Chrome supplemental evidence shows better overall feature readiness and lower sampled memory, with an observed small-model full-readiness regression in every pair and slower geometry completion on several models. The target corpus improvement and universal absence of performance regressions are not established. Geometry completion and full feature readiness are reported separately.

The original Chrome strict audit remains failed because it rejected a resource-error console entry in every case. A separate static navigation on each frozen artifact authoritatively ties its reproduced error to the missing local Vercel analytics endpoint. Original console text, ordering and pre-load timing match that explanation, but original per-event resource URLs were not retained. The supplemental environmental disposition is explicit and does not rewrite the original audit or introduce a blanket console-error exception. Previously skipped cross-side and across-pair geometry, search and selected store comparisons pass.

The original Firefox cohort is invalid under its required memory-sampling rule. Its large-model candidate outlier includes a failed read of a transient owned child and an unusually late renderer-ready event. The executable name alone does not prove a browser crash, and historical focus was not recorded. Later focused and deliberately backgrounded functional controls pass and establish a scheduling mechanism on both versions; they do not prove the historical cause or qualify a Firefox corpus improvement. The prepared recovery cohort remains unrun.

The native observable oracle compares exact public processing output with repeated baseline output. It exercises streaming, deferred data, cancellation, stream-only and instanced modes with actual property, color, texture and instance witnesses. Coverage is bounded to the recorded fixtures and mode combinations. It is baseline parity, not independent IFC semantic truth, topology closure, cross-platform determinism or bytewise parity of every browser model. Timing and cache counters are intentionally excluded from exact comparison.

Browser functional witnesses exercise actual panels, properties, spatial paths, search and GPU picking. Geometry fingerprints retain counts and aggregate geometry channels; they do not prove closure or bytewise identity of all vertex buffers. Complete property-value parity is not inferred from property counts. Cache-save completion is observed within the memory window when expected; this does not itself establish cache-hit reload correctness or exact cache bytes. Separate final functional checks on the frozen shipping baseline and candidate pass ordinary single-model and federated selection, actual panels/search/GPU picking and primary cache-hit reopening. Exact retained property/path/source witnesses match between sides and across the primary cache reopen. The secondary GPU hit resolves the intended model but a different entity from its property/search witness, consistently on both sides. Partial source-accessor identity remains unobserved, and these small-model runs do not exercise deferred index rows. Earlier mixed-coordinate federation failures remain a separate baseline limitation; ordinary federation success does not repair or overwrite them.

Primary aggregation is predeclared: compute each model's median paired candidate/base ratio, then the equal-model geometric mean. Do not multiply separate layer or historical experiment ratios. Native full-call includes file read and the complete processing return; output fingerprinting is outside the timer. Native process peak memory includes later fingerprinting and shutdown. Browser full readiness includes geometry, metadata, renderer and complete search; sampled memory continues through readiness and expected cache completion. RSS can double-count shared pages, sampled concurrent physical footprint differs from a process lifetime peak, and OS file caching is uncontrolled despite fresh application processes.

## Contents

- `provenance.jsonl`: exact source and artifact identities, runtime-manifest commitments, build configuration and oracle lineage.
- `native.jsonl` and `layers-native.jsonl`: every retained native run, counts, ordered fingerprints and timings.
- `chrome.jsonl` and `firefox.jsonl`: every retained browser run, original audit status, readiness, feature and memory/cache witnesses.
- `layer-B-chrome.jsonl`: final matched own-layer browser subset, retaining its strict-audit failure and reviewed diagnostic disposition.
- `summaries.jsonl`: numeric paired summaries and explicit verdict status.
- `native-oracle.jsonl`: bounded exact-output cases and actual observable coverage.
- `functional.jsonl`: final ordinary federation/cache functional witnesses, exact comparison results and coverage limitations.
- `dispositions.jsonl`: resource-error review, Firefox failure, functional controls and explicitly unrun research.
- `manifest.jsonl`: hashes of this projection bundle.

Private fixture names and files, property payloads, coordinates, screenshots, profiles, raw browser diagnostics and user paths are intentionally excluded. Stable corpus labels are retained. Historical PGO, scanner, bulk-column, ordinal, server and renderer prototypes are not qualified by this retained shipping evidence. A prepared script does not establish that an experiment ran. Attribution profiles explain candidate selection and bounded opportunities; sampled or nested CPU scopes do not constitute an end-to-end speedup.

CI, review, merge and production verification are separate live gates. Their status must be checked against the exact landing head. This bundle does not certify an unobserved future head or deployment.
