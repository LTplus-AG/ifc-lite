# One numeric literal grammar and STEP binary literals (#7778, F4-1)

`behaviour.oracle.patch` is the revert-oracle mutation for the F4-1 PR. The PR adds `Token::Binary`, `AttributeValue::Binary`/`as_binary_hex`, `read_step_number`/`StepNumber`, `decode_step_binary` and `binary_textures_refused`, which the changed tests import, so a whole-change revert does not compile (INCONCLUSIVE). The patch keeps every item and restores ONLY behaviour the tests pin: the tokenizer's pre-F4-1 number grammar (no leading `.`, no dotless exponent), a binary whose unused-bits digit is above `3`, `decode_step_binary` accepting a non-zero indicator, and the texture reader not counting a refused binary. Once `rust/core/src/parser/numeric_literal.rs` carries `read_step_number` on `main`, the ordinary whole-change revert resumes.
