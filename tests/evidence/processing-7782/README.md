# One native entry point (#7782, C4-1)

`behaviour.oracle.patch` is the revert-oracle mutation for the C4 stack. C4-1 adds `ifc_lite_processing::{process, ProcessingRequest, Batching, Features, ProcessingSink, FrameEvent}` (`rust/processing/src/processor/{request,sink}.rs`); a whole-change revert deletes them under the changed tests, which is a build break. The patch keeps every item and disables ONLY behaviour the tests pin: the `on_frame` event, the `ClosureSink` baked-basis slot, `from_streaming`'s `fast_first`, and the id allow-list of `process_geometry_filtered_with_quality_and_ids`. Once `rust/processing/src/processor/request.rs` is on `main` the ordinary whole-change revert resumes.

`scan-class.oracle.patch` is the mutation for C4-5 (`rust/processing/src/scan.rs`, the `ScanClass` keyword table). It keeps the module and breaks only the table: `IFCMAPPEDITEM` unclassified, the fills wire code shared with voids, `IFCPROPERTY...` records unclassified, `IFCRELAGGREGATES` stashed with voids. Once `scan.rs` is on `main` the ordinary whole-change revert resumes.

`type-geometry-plan.oracle.patch` is the mutation for C4-7a (`rust/processing/src/plan.rs`, `TypeGeometryPlan`, and `rust/wasm-bindings/src/api/type_geometry_cache.rs`). A whole-change revert deletes both modules under the changed tests (`plan_tests.rs`, `type_geometry_cache_tests.rs`, and the reader-parity test in `quick_metadata_tests.rs`, which calls `plan::type_representation_maps`), so they cannot compile. The patch keeps every item, signature and import and breaks only pinned behaviour. First, `type_representation_maps` loses its bare `EntityRef` arm, so the browser reads RepresentationMaps list-only, as main did. The parity test and `issue_7782_shared_candidates_admit_bare_and_list_maps` must fail. Second, `observe_mapped` keeps the first-seen template instead of the minimum id, so the reverse-order half of `issue_7782_template_selection_is_independent_of_scan_order` must fail. Third, a partly installed prepass membership column is discarded and overwritten by fallback discovery, so `issue_7782_type_membership_fallback_preserves_installed_columns_and_resets` must fail. Fourth, the export data model's type rows read RepresentationMaps list-only through `ref_list` again, so `issue_7782_export_rows_match_type_meshes_for_bare_and_list_maps` must fail: a bare map still meshes #300 natively, but the row is missing (#1518).

Orientation: like every `--mutation`, the patch is written as `git diff base...head` and the oracle reverse-applies it. The `-` side is the mutated code and the `+` side is the branch head. Regenerate it by editing head into the mutated form and running `git diff -R`. Do not use the forward "apply to break" orientation. This committed patch is the primary, durable mutation proof. The external C4-7a mutation driver is supplementary cross-side evidence: it covers native-only mutations, the batch reader and the WASM contract, which the oracle's changed Rust tests do not build. Once `plan.rs` is on `main` the ordinary whole-change revert resumes.
