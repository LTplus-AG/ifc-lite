## Residual findings

1. **Acceptance blocker: workflow dependency absent.** `tools/localization-french/workflow.mjs:12` imports `./workflow-verdict.mjs`, which was absent at the final source inspection. The script therefore cannot start. It already calls `collectPageErrors(page, report)` for the main page and, correctly, for the fresh fr-CH page before navigation (line 132); its finalizer calls `workflowFailed(report)` (line 137). Supply the helper and verify that a nonempty `report.errors`, a failed check, or a fatal error produces failure. Preserve fresh-page collection. Existing call sites alone do not establish the helper's behavior. This may be an integration write in progress, but cannot be accepted until present and exercised.

2. **Acceptance blocker: stale exact-copy exception.** The final loaded-object comparison found **536** identical English/French messages but **537** entries in `apps/viewer/src/i18n/locales/fr-identical.json`. The sole stale entry was `idsPanel.notApplicableCount`, whose actual French value is now `{ one: '{countDisplay} non applicable', other: '{countDisplay} non applicables' }`. `french-catalogue.test.ts` requires exact equality between the exception-key set and actual identical messages, so it will fail. Remove that stale exception; preserve the improved translation. All remaining identical keys had matching pinned values and nontrivial explanations in the probe.

3. **Cross-module quoted-name mismatch.** `changeSets.empty` and `changeSets.noActive` in `locales/fr/change-sets.ts:12–13` promise a set named « Modifications non enregistrées ». `store/slices/mutation-history-record.ts:21,59` actually creates `Unsaved changes`; `components/viewer/change-sets/ChangeSetPanel.tsx:80` displays the French promise and its row renders `name` verbatim. The quoted name therefore cannot be found after the edit. For this bounded locale change, remove the exact-name promise: e.g. « Aucun jeu de modifications pour le moment. Votre première modification en crée un automatiquement, ou créez-en un maintenant. » and « Aucun jeu de modifications actif. Votre prochaine modification en créera un automatiquement. » Do not translate existing user/content names. The uncatalogued default name itself is a legacy boundary, not grounds for a sweep.

4. **Appearance precedence wording implies geometric overlap.** `appearanceAssignmentList.description` says « sur les objets qui se chevauchent ». In `lib/appearance/assignments/resolve.ts:69–77`, precedence depends on the same product ID being claimed by multiple assignments in the same model, not on physical intersection of objects. `AppearanceAssignmentList.tsx:29–36` shows this instruction above the reviewed assignments. Prefer « Les affectations ultérieures remplacent les précédentes pour les éléments communs à plusieurs affectations. Exclure un élément ici conserve toute affectation précédente. » This also fixes the glossary in that instruction. Nearby `reviewAriaLabel` and `reviewButton` still say objets; use éléments to match the now-correct summary. This is a localized clarification of ambiguous English, not a change to assignment behavior.

## Verified coverage and semantics

Bounded read-only probes used installed `node --import tsx --input-type=module` with stdin, importing actual locale/catalogue/registry objects. They did not run the writing audit script.

- Loaded all **158** French feature modules through `fr.ts`; compared all eager/lazy English exports: **10,607 English keys / 10,607 French keys**, no missing keys, zero existing-validator problems.
- Exercised **466** plural messages with 0, 0.5, 1, 1.5, 2, 2.5 and 1,000,000. Intl categories were respectively one, one, one, one, other, other, many. All non-count context sentinels survived and no named placeholders remained unresolved. Numeric `count` interpolation uses raw decimal text; this probe establishes plural selection, not localized decimal formatting for fractional element counts.
- The known `appearanceAssignmentList.summaryProducts` repair is present: actual resolution gives `0 élément`, `1 élément`, `2 éléments` and `1000000 d'éléments`. Its real caller passes `row.productIds.length` and composes products/excluded/overridden through `appearanceAssignmentList.summary`.
- `semanticAssist.idsSkipsModels` correctly says « Le brouillon IDS ne vérifie pas 2 modèles chargés… ». `RequirementDispatch.tsx:160–162` supplies `loaded.unchecked`, gated on a positive unchecked count. This denotes the number of unchecked models, not a model identifier. No correction needed.
- Before lazy English registration, the catalogue validator returned no problems and `retainedGeometry.shapeOnlyReason` resolved in French while absent from eager English. Startup activation with real French data negotiated fr-CH, persisted `?lang=fr`, reused the saved locale and switched back via `?lang=en`; HTML language followed in the supplied document object. Source inspection of `store/ids-locale-sync.ts` confirms French mapping and preservation of an explicit IDS choice on mere catalogue notifications. The mounted IDS test was read, not executed here.
- Reviewed destructive/negative messages including change-set discard (model edits remain), script delete composition (quoted name plus irreversible consequence), measurement clearing, private error-report deletion (public content remains), storage conflict/restore/import warnings, BCF uncertain publication, IDS audit/export limits and semantic draft withdrawal. No reversed negation or lost destructive consequence found in these samples.
- Checked glossary-sensitive storey/properties/quantities/collision/section messages and the real assignment and IDS callers. Storey messages inspected use étage; filters preserve negation. Remaining objet wording is noted above rather than declaring global glossary perfection.
- Cross-references for « Détecter toutes les collisions », « Rechercher les doublons », « Masquer les contacts », « Supposé », « Heure de la journée » and « Réessayer toutes les bibliothèques » agree with their target catalogue labels. The change-set mismatch is the concrete exception found.
- No copied English prose was found in the loaded identical-message review or targeted English-fragment scan. Shared long values were schema/placeholder expressions, browser names/versions and a CLI command. Exact external captions such as `Create Key` and InfluxDB terms have explicit reasons. This does not assert that uncatalogued legacy UI is translated.
