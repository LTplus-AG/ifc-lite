# German catalogue semantic review

Independent **LLM review**, 2026-11-05. This is **not native-speaker acceptance** or runtime acceptance. Reviewed the live working tree over HEAD `f6ffa4fc655d6ec29c3c8f0baaaacde76bb4899f`; concurrent translation work may supersede these observations. Only this report was written; no builds, tests, browser runs, translation edits, delegation, or commits.

## Findings

1. **Major — GLB colour-source guidance reverses the implemented sources (inherited from English).** Keys: `geometryExport.glb.colorSourceShading`, `geometryExport.glb.colorSourceRenderingHint`, `geometryExport.glb.colorSourceShadingHint` in `apps/viewer/src/i18n/locales/de/geometry-export-dialogs.ts`. German calls shading “Schattierung (SurfaceColour)” and says rendering uses authored `DiffuseColour`; English makes the same claims (`catalogues/geometry-export-dialogs.en.ts:47`). However, `components/viewer/GLBExportDialog.tsx:279` substitutes `m.shadingColor` only for shading. The canonical resolver `rust/processing/src/style/surface.rs:30`, implemented at lines 53–80, makes apparent colour `SurfaceColour` (modulated only by a numeric diffuse factor), and shading the distinct `DiffuseColour` RGB override. A user choosing based on these descriptions can export the opposite colour source. Repair both EN and DE; suggested DE respectively: **“Schattierung (DiffuseColour)”**; **“Verwendet SurfaceColour; ein numerischer DiffuseColour-Faktor wird berücksichtigt. Eine separate DiffuseColour-RGB-Farbe ersetzt SurfaceColour nicht.”**; **“Verwendet eine separat angegebene, abweichende DiffuseColour-RGB-Farbe; andernfalls die sichtbare Rendering-Farbe.”** These identifiers are established by the canonical resolver and root schema/style policy, not inferred from casing.

2. **Minor — section box is misidentified as a field.** Keys `sectionTool.box.fitSelectionTitle` and `sectionTool.box.handleTitle` (`locales/de/section-tool.ts:19`, `:21`) currently say “Passen Sie das Feld an die Auswahl an” and “Ziehen Sie, um diese Fläche des Felds zu verschieben”. English explicitly says “box”. `components/viewer/tools/SectionActivePlaneRow.tsx:91` fits the section box to selection bounds; `SectionBoxVisualization.tsx:119` moves one of its faces. There is no field being fitted or moved. Suggested repairs: **“Schnittbox an die Auswahl anpassen”** and **“Ziehen, um diese Fläche der Schnittbox zu verschieben”**. This also restores consistency with `sectionTool.box.sizeAria`.

3. **Minor — cross-section is translated as a generic portion.** Key `sectionTool.drawing.openTitle` (`locales/de/section-tool.ts:38`): “Öffnen Sie den 2D-Abschnitt der ausgewählten Ebene”. English says “2D section”; `SectionActivePlaneRow.tsx:108` clears the drawing and opens the drawing panel so it regenerates against the current cut, with this tooltip at line 275. Suggested repair: **“2D-Schnitt der ausgewählten Schnittebene öffnen”**. “Abschnitt” does not name the generated cross-sectional drawing and conflicts with the adjacent “2D-Schnitt” label.

4. **Minor — drag completion asks for release in the approval/sharing sense.** Key `measure.hint.dragActive` (`locales/de/measure.ts:75`): “Zum Abschluss freigeben”. English is “Release to complete”. `components/viewer/tools/measure-modes/readouts.ts:89` selects this hint specifically for an active drag measurement, paired with “Zum Messen ziehen”. Suggested repair: **“Zum Abschließen loslassen”**. The required action is releasing the drag, not approving or sharing the measurement.

## Coverage and limits

Read `ACCEPTANCE.md`, supplied root instructions, machine/fleet policy, and viewer/Rust instructions. Reviewed load/no-model guidance, hierarchy/storeys and removal warnings, properties/selection and inherited edits, measurement quantities/negations, section controls, IDS results/cardinality/corrections, IFC/geometry/anonymized export, and sampled broader terminology and filter negations. Caller checks included `PanelModelGate`, `HierarchyRowActions`, `useConfirmRemoveModel`, `SelectionSummaryPanel`, `PropertySetCard`, `IDSPanelResults`, `IDSCorrectionDialog`, export option controls, and the section/measurement callers above.

No additional evidence-backed translation defect was established in those sampled workflows. Removal copy retains the loss of unexported changes; IDS copy distinguishes failure from non-applicability; selection comparison limits remain explicit. This is not an exhaustive catalogue clean bill. A bounded comparison of explicit IFC/Pset/Qto identifier tokens against corresponding English message lines found no missing tokens; this does not certify every identifier or dynamically supplied value. No identifier renaming is recommended merely because a word is CamelCase.

Catalogue completeness, loaded-object validation, real IFC rendering, narrow/wide layouts, accessibility in the browser, persistence/negotiation, and native-speaker acceptance remain unverified by this review. Old campaign directories were not inspected or changed.
